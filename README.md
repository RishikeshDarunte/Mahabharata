# Mahabharata

An interactive web-based presentation of the **Mahabharata**, one of India's greatest ancient epics.

## About the Project

This project is a static website created to present the story, characters, events, and important aspects of the Mahabharata in an accessible and visually engaging format.

The website is built using standard web technologies and can be deployed directly as a static website.

## Features

- Detailed Mahabharata content
- Interactive and user-friendly interface
- Information about major characters
- Important events and stories
- Responsive web design
- Works on modern web browsers
- No backend or database required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React
